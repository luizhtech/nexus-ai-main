# Nexus AI

Você é responsável por criar uma landing page de nível internacional para um produto SaaS de tecnologia.

O objetivo é criar uma experiência visual comparável em qualidade, acabamento, narrativa e profissionalismo à landing page do MBA DevClub.

IMPORTANTE:

- NÃO copie layouts, textos, identidade visual ou elementos exclusivos da referência.

- Utilize apenas o mesmo nível de qualidade como objetivo.

- O resultado deve possuir identidade própria.

========================

PRODUTO

Crie a landing page para o produto chamado NEXUS.

Nexus é uma plataforma de Inteligência Artificial para equipes de engenharia de software.

Ela centraliza:

- documentação inteligente

- revisão de código por IA

- gerenciamento de tarefas

- colaboração entre desenvolvedores

- dashboards

- arquitetura visual

- automações

- integração com GitHub, Jira, Slack e Vercel

========================

OBJETIVO DA EXPERIÊNCIA

A experiência deve parecer a apresentação de um produto real.

Não quero uma landing page composta apenas por blocos empilhados.

Quero uma narrativa contínua.

Cada seção deve preparar naturalmente a próxima.

O usuário nunca deve sentir que chegou ao fim de uma seção e iniciou outra.

Tudo precisa fluir.

========================

HERO

Criar um Hero ocupando toda a tela.

O Hero precisa transmitir imediatamente:

tecnologia

confiança

inovação

qualidade

O Hero deve conter:

- headline extremamente forte

- subtítulo curto

- CTA principal

- CTA secundário

- mockup profissional do produto

- iluminação discreta

- background tecnológico

- animações suaves

- grid moderno

- elementos respondendo ao movimento do mouse

O mockup deve parecer uma aplicação real.

========================

Cada seção precisa possuir identidade visual própria.

========================

IMPORTANTE

Antes de implementar qualquer componente:

Planeje toda a experiência.

Planeje a navegação.

Planeje o storytelling.

Planeje a hierarquia visual.

Planeje as animações.

Depois implemente.

Se alguma parte parecer genérica, reprojete essa parte antes de continuar.

A entrega deve parecer um projeto desenvolvido por uma equipe de produto experiente durante vários meses.

Não simplifique decisões de design para terminar mais rápido.

Priorize qualidade acima da velocidade.
